# Система управления пунктом велопроката

Веб-приложение для управления велосипедами, клиентами и арендами в пункте велопроката.

## 🏗️ Архитектура

### Core (Доменный слой)
- **Entities** - бизнес-сущности (BikeModel, Bike, Client, Rental)
- **Enums** - перечисления (BikeType)
- **Repositories** - интерфейсы паттерна Repository

### Infrastructure (Слой данных)
- **Data** - DbContext и DataSeeder с тестовыми данными
- **Repositories** - реализации репозиториев

### Application (Слой бизнес-логики)
- **Services** - сервисы с бизнес-логикой (BikeService, ClientService, RentalService, AnalyticService)
- **Helpers** - вспомогательные классы (MapperHelper)

### Application.Contracts (Контракты)
- **Dtos** - модели данных для запросов/ответов
- **Services** - интерфейсы сервисов

### Api.Host (Веб-слой)
- **Controllers** - REST API контроллеры

### AppHost (Aspire оркестратор)

## 🚀 Функциональность

### Управление данными
- ✅ CRUD операции для всех сущностей
- ✅ Валидация и бизнес-правила
- ✅ Навигационные свойства и связи

### Аналитические отчеты
- ✅ Информация о всех спортивных велосипедах
- ✅ Топ-5 моделей по времени аренды
- ✅ Топ-5 моделей по прибыли от аренды
- ✅ Статистика времени аренды (мин, макс, среднее)
- ✅ Суммарное время аренды по типам велосипедов
- ✅ Клиенты, бравшие велосипеды больше всего раз

## 🛠️ Технологии

- **.NET 8** - основная платформа
- **Entity Framework Core 8** - ORM
- **ASP.NET Core Web API** - REST API
- **SQL Server** - база данных
- **Swagger** - документация API
- **Aspire** - оркестрация приложений
- **xUnit** - тестирование

## 📋 Сущности

### BikeModel (Модель велосипеда)
- Тип велосипеда (Road, Mountain, Hybrid, Sport, Electric, Bmx)
- Технические характеристики (размер колес, вес, максимальный вес)
- Цена часа аренды

### Bike (Велосипед)
- Серийный номер
- Цвет
- Связь с моделью

### Client (Клиент)
- ФИО
- Телефон

### Rental (Аренда)
- Время начала аренды
- Продолжительность в часах
- Связи с велосипедом и клиентом
